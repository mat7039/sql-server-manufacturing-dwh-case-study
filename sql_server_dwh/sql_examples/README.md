# SQL Examples

This folder keeps a few short SQL samples from the warehouse side of the project.

They are not copied production scripts. The point is just to show the general style of the implementation:
- one example of SCD2 handling
- one example of fact loading with date-based lookups
- one example of manual business mapping used in reporting logic

I kept them intentionally short. I wanted them to be readable in a few minutes, not to feel like a dump of internal code.
