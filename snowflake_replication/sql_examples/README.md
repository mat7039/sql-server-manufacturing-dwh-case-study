# SQL Examples

These are short SQL examples from the Snowflake side of the project.

They are not meant to be full deployment scripts. The goal is just to show the shape of the replication layer:
- how the stage is defined
- how one table is loaded from stage
- how the full snapshot refresh is wrapped in a stored procedure

I kept the examples small on purpose. They are meant to be skimmed, not studied for half an hour.
